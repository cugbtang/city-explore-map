# 儿童城市探索地图 🗺️

一个面向 **4–10 岁儿童**的城市探索工具：帮孩子在周末发现身边的公园、博物馆、图书馆、动物园……并用「地图 + 足迹 + 日记 + 任务卡」把探索变成可持续的家庭习惯。

> 设计取向：单文件、零依赖、数据全部本地保存。无需登录、无需服务器、不上传任何数据，**对儿童应用更友好、过审更简单**。

---

## ✨ 特性

- **🗺️ 探索地图**：示意地图（SVG）标记地点，可缩放、可切换地图/列表视图；去过/没去过不同标识。
- **🎯 周末去哪玩**：5 步条件筛选（玩法 / 室内外 / 时长 / 预算 / 区域）+ 「随机抽一个」。
- **📍 地点详情**：信息结构化展示（票价、是否需要预约、建议时长、交通等），空字段不编造；可「想去 / 去过 / 生成任务 / 写日记 / 编辑 / 删除」。
- **❤️ 愿望清单 / 👣 探索足迹 / 📖 探索日记**：足迹支持本地照片（自动压缩、带容量保护），日记倒序展示、删除二次确认。
- **🎲 随机探索 / 🎯 任务卡 / 🗓️ 周末计划 / 🏆 成就墙 / 📊 统计**：任务卡按分类本地生成模板，无需 AI；成就墙由真实记录解锁，无排名。
- **👨‍👩‍👧 家长管理**：增 / 改 / 删地点、删演示、JSON 导入导出、清空（均二次确认）、恢复演示。
- **🌆 城市切换**：可切换到任意城市，从空白或该城市真实地点起步。
- **💾 本地持久化**：全部数据存 `localStorage`，刷新不丢；异常处理（空数据 / 无结果 / 格式错误 / 容量不足）均有友好提示。

## 🚀 用法一：直接用浏览器打开

无需任何安装。把 `www/index.html` 双击用浏览器打开即可使用（电脑、手机浏览器均可）。

- 演示数据默认是 **北京 10 个真实场所**，已清楚标注「演示地点，请替换」。票价、预约等仅供参考，请家长核实后自行修改。
- 在「家长管理 → 城市切换」可切换到你的城市，并「删除全部演示地点」后添加真实地点。

## 📦 用法二：打包成可上架 App（Capacitor）

本仓库已附带 Capacitor 工程配置，可将同一个 HTML 打包为 **iOS + Android** 双端 App。

### 前置条件
- Node.js 18+
- Android 端：Android Studio + Android SDK（Windows / macOS 均可）
- iOS 端：macOS + Xcode（Apple 开发者账号 $99/年）

### 步骤
```bash
cd city-explore-app
npm install

# Android
npx cap add android        # 生成原生工程（需已装 Android Studio + SDK）
npx cap sync               # 把 www/index.html 同步进原生工程
npx cap open android       # 在 Android Studio 里 Build → Generate Signed Bundle → 上架 Google Play / 应用宝 / 华为等

# iOS（需 macOS）
npx cap add ios
npx cap sync
npx cap open ios           # 在 Xcode 里 Archive → App Store
```

> 之后只要改了 `www/index.html`（换城市、加地点等），跑一次 `npm run sync`（即 `npx cap sync`）即可同步进两个原生工程。

### 关键配置说明
- `capacitor.config.json` 中 `androidScheme: "https"`：**关键**——用本地 https 服务托管页面，避免 `file://` 下 `localStorage` 失效导致数据丢失。
- `appId` 默认 `com.cityexplore.map`，可按你的开发者账号修改。
- 应用不申请摄像头 / 定位权限；「从相册选照片」走系统选择器（用户主动触发），对儿童应用更友好。

## 🔒 隐私政策要点

- **数据全部本地存储**：所有地点、足迹、日记、照片仅保存在本机 `localStorage` / 浏览器沙箱，**不会上传任何服务器**，也无第三方统计 / 广告 SDK。
- **无账号体系**：不需要注册、登录，不产生云端个人信息。
- **照片**：仅存于本机，不上传；删除数据时会一并清除。
- 完整说明见 [`PRIVACY.md`](./PRIVACY.md) 与 App 内「家长管理 → 隐私政策」页。

## 🛠️ 如何替换 / 添加城市与地点

1. 打开 App → 「家长管理 → 城市切换」，输入所在城市并保存。
2. 若仍存在旧城市演示数据，按提示清除。
3. 「家长管理 → 新增地点」手工录入真实场所；或「导入 JSON」批量导入。
4. 字段说明（与内置数据结构一致）：名称、城市、分类（公园绿地/动物世界/科学探索/图书馆/博物馆/文化体验/城市漫步/雨天室内/自然教育/游乐体验）、室内外、建议时长、费用、是否需预约、区域、一句话简介、坐标（示意 x/y）、标签、开放时间、交通、贴士。

## 🤝 贡献（Issue / PR 流程）

本仓库用 **Issue 跟踪需求 + PR 实现** 的协作方式：

1. 在 Issues 中选一个待办（如「好友同去」「月度探索日历」），认领并讨论。
2. 从 `main` 切出 `feat/xxx` 分支实现。
3. 提交 PR，正文关联对应 Issue（如 `Closes #4`）。
4. 评审合并后该 Issue 自动关闭。

欢迎提 Issue 反馈 bug 或建议新功能。
