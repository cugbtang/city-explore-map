🔒 隐私政策

儿童城市探索地图 · 最后更新 2026-10-29

一句话结论

本应用不收集、不上传任何个人信息。你在应用里记录的一切，都只留在你自己的设备上。

我们收集什么

什么都不上传。应用运行在本地，没有任何网络请求会发送你的数据。

你主动录入的内容仅保存在本机：

  • 地点信息（名称、分类、票价、开放时间等你填写的内容）
  • 探索足迹、日记与本地照片
  • 愿望清单、周末计划、成就进度
  • 目标城市设置

存储位置：浏览器 / WebView 的 localStorage 沙箱（ Capacitor 安卓端以本地 https 服务托管，确保存储可用）。

我们「不」做什么

  • 不要求注册 / 登录，无账号体系
  • 不连接任何服务器，无云端备份（如你需要可手动导出 JSON 自行保存）
  • 不含任何第三方统计、广告或追踪 SDK
  • 不申请摄像头、定位权限；「从相册选照片」由你主动触发，仅存本机
  • 不向儿童展示广告或引导外部购买

儿童数据处理

本应用面向儿童使用，但所有数据均由家长在设备上管理，且不离开本机。我们不向任何第三方提供儿童相关数据，因为没有任何数据被传出设备。

你拥有的控制权

  • 「家长管理 → 导出数据」可把全部内容导出为 JSON 自行保存
  • 「家长管理 → 清空全部数据」可一键删除本机所有内容
  • 卸载应用即清除相关本地数据

联系方式

如对本隐私政策有疑问，可通过项目仓库（GitHub: cugbtang/city-explore-map）提 Issue 联系。

本政策为说明性文本，不构成法律意见；上架前请结合目标市场法规（如 COPPA / GDPR-K）酌情补充。
